# Learning Swift

My work from a 10-week Swift App Development course (Oct to Dec 2026), working toward Apple's App Development with Swift certification.

This repo holds my weekly notes, exercises, and projects. It's also the raw material for a Swift course I'm building, written for people coming from JavaScript and visual/creative backgrounds.

## Structure

| Folder | What's in it |
| --- | --- |
| `weeks/` | One folder per week: notes from class plus the exercises I completed |
| `projects/` | Larger apps. Strong ones graduate to their own repos |
| `concepts/` | One file per Swift concept, explained in my own words. This becomes the course outline |
| `templates/` | Starting points for weekly notes, exercises, and concept pages |
